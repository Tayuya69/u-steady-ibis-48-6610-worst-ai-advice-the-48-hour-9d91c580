One line of the worst possible advice an AI could give, in 140 characters or fewer: reply to a phishing email with your password so the sender can confirm you are the real account owner. Built for make.fun's "Worst AI Advice: The 48-Hour Tight Line Open" bounty — `main.ts` writes the one-liner to `/output/entry.txt`, deterministically, with no network and no dependencies.

## Run it

```sh
node main.ts
```

Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written.
